# راهنمای پنل مدیریت

## هدف

پنل مدیریت برای کنترل کاربران، گروه‌های دسترسی، عضویت‌ها و عملیات خودکار سامانه AP Emlaki استفاده می‌شود. دسترسی این بخش فقط برای کاربران دارای نقش administrator فعال است.

## بخش‌های پنل

### Users

مدیریت حساب‌های کاربری، وضعیت فعال یا غیرفعال، گروه و تغییر رمز عبور. برای ایجاد کاربر جدید، نام کاربری و رمز عبور را وارد کنید و در صورت نیاز گروه را انتخاب کنید.

### Groups and rights

مدیریت نقش‌ها و ماتریس مجوزها. هر گروه می‌تواند برای entityهای مختلف مجوزهای افزودن، ویرایش، حذف، جست‌وجو، چاپ، نقشه و import داشته باشد.

### Memberships

اتصال کاربران به گروه‌های دسترسی. عضویت تعیین می‌کند کاربر کدام مجموعه مجوزها را دریافت کند.

### Automation

اجرای دستی عملیات ثبت‌های دوره‌ای و تخصیص شماره بعدی اسناد. این عملیات را فقط پس از بررسی وضعیت داده‌ها اجرا کنید.

## جست‌وجوی پنل

کادر `Find anything in administration` عنوان، توضیح و محتوای چهار سکشن پنل را جست‌وجو می‌کند. جست‌وجو به‌صورت لحظه‌ای انجام می‌شود و سکشن‌های نامرتبط و تب مربوط به آن‌ها مخفی می‌شوند. میانبر `Ctrl + K` یا `Cmd + K` فوکوس را روی کادر جست‌وجو قرار می‌دهد.

## اصول رابط کاربری

- نوار کناری برای راهبری ماژول‌ها و دسته‌بندی‌های اصلی است.
- نوار بالایی شامل تغییر پوسته، زبان، import، رمز عبور و خروج است.
- سطوح glass برای نوار کناری، topbar و فرمان‌های مهم استفاده می‌شوند.
- در سیستم‌هایی که شفافیت یا حرکت را کاهش می‌دهند، رابط به سطح مات و حرکت حداقلی برمی‌گردد.
- دکمه‌های تغییر‌دهنده داده باید همراه CSRF token ارسال شوند.

## روش کار معمول مدیر

1. وارد حساب مدیریتی شوید.
2. از نوار جست‌وجوی مدیریت یا سکشن‌های پنل بخش مورد نظر را پیدا کنید.
3. برای تغییر دسترسی، ابتدا گروه را انتخاب و سپس ماتریس مجوز را باز کنید.
4. بعد از تغییر کاربر یا گروه، وضعیت و نتیجه عملیات را از پیام موفقیت یا خطا بررسی کنید.
5. عملیات Automation را فقط برای داده‌های آماده اجرا کنید.
